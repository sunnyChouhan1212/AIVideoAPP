# AI Video Generator 🎬

Generate AI voice videos with subtitles using:
- Streamlit
- gTTS
- FFmpeg
- Faster Whisper

## Features

- Upload video
- Replace audio with AI speech
- Auto subtitle generation
- Burn subtitles into video
- Export final MP4
